description: Audit the current stage against its acceptance criteria, then stop
---
Audit the current stage.

Compare the actual implementation against the stage's acceptance criteria.

Verify:

- Functional requirements.
- Code implementation.
- Tests and validation.
- Documentation.
- Outstanding issues.
- Learning objectives.

Report each acceptance criterion as:
- Passed
- Failed
- Not verified

Do not claim completion when criteria remain unverified or failed.

If the stage is incomplete, explain what remains.

If it is complete:

1. Update project documentation.
2. Summarize the technical knowledge acquired.
3. Present the stage completion report.
4. Stop and wait for my approval.

Do not automatically proceed.
